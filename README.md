# Sterling Hunter

A hunter helper for WoW Forever, part of the Sterling add-on family.

## Features

- **Ammo auto-buy** when you open a vendor
  - Picks arrows or bullets from your ranged weapon
  - Current ammo only, best usable, or your own priority list
  - Skips ammo you can't use yet, never downgrades (optional)
  - Fill your quiver or ammo pouch, or keep a set number of stacks
  - Gold floor, and asks first before a big purchase
  - Hold Shift while opening a vendor to skip it once
- **Low ammo warning** on screen with a sound, and again when you run out
- **Aspect reminder** if Aspect of the Cheetah or the Pack is on in combat

Type `/sth` in game for the settings window.

## Install

Install with [WowUp](https://wowup.io): **Get Addons > Install from URL**, then paste:

```
https://github.com/SterlingAddons/SterlingHunter
```

Or download the zip from [Releases](https://github.com/SterlingAddons/SterlingHunter/releases) and unzip it into `_forever_\Interface\AddOns\`.
